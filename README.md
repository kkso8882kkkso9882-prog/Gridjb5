## สกิลวิธีการทำงาน
* คิด — วิเคราะห์เป้าหมายและข้อจำกัด

* ถาม — ถามข้อมูลที่จำเป็นจนเข้าใจตรงกัน

* คิด — วางแผนก่อนลงมือ

* ลงมือ — ทำตามข้อกำหนดที่ตกลงกัน

* ตรวจ — ตรวจผลงานและความถูกต้อง

* คิด — วิเคราะห์ปัญหาหรือสิ่งที่ยังขาด

* แก้บั๊ก — แก้เฉพาะปัญหาที่พบ โดยไม่แก้ส่วนอื่นที่ไม่ได้สั่ง

* ตรวจว่าเสร็จหรือไม่ — ทดสอบผลลัพธ์เทียบกับข้อกำหนด

* ถ้ายังไม่เสร็จ ให้วนกลับไปทำต่อ — ทำซ้ำตั้งแต่ขั้นที่จำเป็นจนกว่าจะผ่านการตรวจ
